# empn-comms-skills

Reusable drafting instructions for the policy-publication pipeline.

## What's here

| File | What it does |
|---|---|
| `linkedin-draft.md` | Turns a scheduled paper into a LinkedIn post in house voice |

## How they're used

The pipeline fetches the raw file at runtime. This repo is the single
source of truth — editing a skill here changes what the pipeline
produces. There is no second copy.

## Changing a skill

Commit messages say what changed and why, so a drop in draft quality
can be traced to a specific edit. Anything touching voice, claims or
attribution is reviewed before it lands.
